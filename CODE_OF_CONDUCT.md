# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

## Our standards

Everyone who takes part in MicKeeper — in issues, pull requests, reviews and discussions — is expected to:

- be respectful and assume good intent;
- give and accept constructive, technical feedback;
- focus on what is best for the users of the app;
- keep conversations on topic.

Not acceptable: harassment, insults or personal attacks, discriminatory language or imagery, publishing others' private information, and other conduct that would be inappropriate in a professional setting.

## Scope

This code applies in all project spaces on GitHub and when someone represents the project elsewhere.

## Enforcement

Report unacceptable behaviour privately to the maintainer through GitHub (the maintainer's profile), or with GitHub's **Report content** option. Reports are reviewed promptly and kept confidential.

The maintainer may edit or remove comments, commits and other contributions that break this code, and may temporarily or permanently block participants who repeatedly or seriously violate it.
